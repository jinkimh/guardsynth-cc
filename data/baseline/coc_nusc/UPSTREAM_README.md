# nuScenes → PhysicalAI-AV (PAD) format + Chain-of-Causation labels

nuScenes v1.0-trainval converted to the NVIDIA **PhysicalAI-AV (PAD)** dataset
layout, with **Chain-of-Causation (CoC) reasoning labels** generated by the
[alpamayo-coc-autolabeler](https://github.com/NVlabs/alpamayo-coc-autolabeler)
using **Qwen3.5-35B-A3B**. Built to run Alpamayo 1.5 SFT on nuScenes without the
gated 133 TB PAD dataset.

## Contents

| Path | What |
| --- | --- |
| `labels/egomotion/*.zip` | Ego trajectory (15-col parquet per clip) from nuScenes CAN bus 50 Hz |
| `camera/` | 4 cameras (front_wide / cross_left / cross_right / tele) as 10 fps mp4 + timestamp sidecars |
| `calibration/` | extrinsics + FTheta intrinsics + vehicle dimensions |
| `reasoning/ood_reasoning.parquet` | **CoC labels** (3,218 events over 743 clips) + per-event validation scores |
| `clip_index.parquet`, `features.csv`, `metadata/` | PAD index files |

## Scale

- **835 scenes** (train 685 = chunk 0–6, val 150 = chunk 7–8)
- **3,218 CoC labels** — clean 2,433 / flagged 785 (strict quality threshold)
- Loadable by the PAD SDK (`PhysicalAIAVDatasetLocalInterface`) and the
  autolabeler's pinned trajdata `pai` plugin with **zero code changes**
  (`dataset_name=pai`).

## Key conversion facts (measured, not assumed)

- **egomotion** from CAN bus 50 Hz; acceleration derived from velocity
  differentiation (CAN accel includes gravity). Quaternion wxyz→xyzw. heading
  error 0.49° vs travel direction on straight segments.
- **camera**: 12 Hz nuScenes JPEG → nearest-to-100 ms-grid → exactly 10 fps mp4
  (`start_pts=0` required by the SDK reader). mean frame time error ~62 ms.
- **tele camera** synthesized from CAM_FRONT centre crop (no telephoto in
  nuScenes) → domain-shifted channel; a 3-camera mode is available.
- 21 CAN-less scenes fall back to `ego_pose`; scene-0188 dropped (span < 17.5 s).

## reasoning parquet schema

`index = clip_id`, column `events` = JSON string:
```json
[{"event_start_timestamp": <int µs>, "cot": "<text>",
  "quality": {...10 validator scores...}, "quality_pass": true}]
```
The SFT loader reads only `event_start_timestamp` + `cot`; `quality*` fields are
ignored by the loader and available for filtering.

## Validation (Qwen3.5-35B self-scored, median)

| stage | metric | median | flagged |
| --- | --- | --- | --- |
| 1 evidence | visual_evidence | 0.90 | 10.6% |
| 2 behavior | behavior_match | 0.95 | 11.8% |
| 3 causal | decision_supported | 0.90 | 10.8% |

Raw per-event labels + scores also under `coc_run_split/` (coc_clean.json /
coc_bad.json).
