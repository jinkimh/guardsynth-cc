# Archive

- `handoff/`: 압축 이관 당시의 package contents와 manifest
- `handoff/packages/`: 원래 `.tar.gz`와 외부 SHA-256 파일
- `imported-root/`: 구조화 이전 작업공간 루트에 있던 과거 문서 사본
- `manifests/`: 이전 부분 manifest
- `research/`: 활성 계획에서 대체된 연구계획

이 디렉터리는 역사적 추적성을 위한 읽기 전용 보존 영역이다. 현재 실행 경로와 무결성 기준은 루트 README와 `MANIFEST.sha256`을 따른다.
