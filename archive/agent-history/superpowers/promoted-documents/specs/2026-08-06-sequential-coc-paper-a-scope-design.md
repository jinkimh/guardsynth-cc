# Sequential CoC 논문 A안 범위 보완 설계

**작성일:** 2026-08-06  
**상태:** 사용자 승인 완료  
**기반 설계:** `2026-08-06-sequential-coc-consistency-experiment-design.md`

## 1. 결정

이번 KIEE 논문은 **동일 장면 내부의 연속 CoC 계약 검증**에 집중한다.
모든 사례에 하나의 공통 형식 의미론을 적용하지만, 서로 다른 장면이나 시나리오의
automata를 하나의 전역 운전ㆍ행동ㆍ제어 모델로 합성하지 않는다.

핵심 연구 질문은 다음이다.

> 연속 CoC를 지속 의무와 해제 조건을 가진 시간적 계약으로 형식화하면, 사건별
> 검사에서 보이지 않는 상태 이월 오류를 검출하고 UPPAAL 반례로 설명할 수 있는가?

## 2. 논문 안과 밖의 경계

### 포함

- 동일 장면의 시간순 CoC 연결
- 공통 계약 IR과 `TRUE/FALSE/UNKNOWN` 증거 의미론
- 의무 시작, 충족 대기, 해제와 위반 상태
- `HOLD_GO_CONFLICT`, `PREMATURE_RELEASE`, `ORDER_VIOLATION`,
  `STALE_OBLIGATION`
- 사건별 기준선과 상태형 Python 검사 비교
- 통제 원본ㆍ변형 40쌍의 기능 평가
- 같은 의미론의 UPPAAL 관찰자, 상태 전이와 반례
- 자연 CoC에서 텍스트만으로 계약 구조를 판독할 수 있는 정도의 기술적 분석
- 궤적이 있는 부분집합의 탐색적 CoC 요구 행동–관측 행동 정합성
- 장면 경계 정책은 출처 불확실성의 보조 사례로만 보고

### 제외

- 여러 장면ㆍ시나리오 automata의 전역 합성
- 출처 근거 없는 장면 간 의무 이월
- 대량 CoC에서 통합 행동 모델 학습
- 사람 운전자 행동 모델 또는 사람의 사고 과정 모델
- Environment–Controller–Plant 폐루프 모델
- adversarial 환경 강건성 또는 timed-game 전략 합성
- 물리적 충돌, 차량 안전, 교통법규 준수 또는 강화학습 성능 주장

## 3. 세 연구 질문의 역할

### RQ1 — 주 정량 질문

**CoC 계약은 시간적으로 일관적인가?**

통제 쌍에서 유형별 검출률, 정상 원본 오탐률, 사건별 검사 대비 상태형 추가 검출,
Python–UPPAAL 판정ㆍ모순 유형ㆍ최초 반례ㆍUNKNOWN 사유 일치를 평가한다.

### RQ2 — 제한된 자연 자료 질문

**자연 CoC 텍스트는 지속 의무, 행동 순서와 해제 조건을 명시하는가?**

영상이나 객체 증거 없이 실제 충족ㆍ해제 상태를 묻지 않는다. 자연 자료에서는
텍스트에 계약 요소가 명시됐는지, 텍스트만으로 시간적 판정을 내릴 수 있는지만
평가한다. 실제 상태가 필요하면 `EVIDENCE_REQUIRED` 또는 `UNKNOWN`이다.

### RQ3 — 탐색적 질문

**CoC 요구 행동과 관측된 사람의 종방향 행동은 어느 정도 겹치는가?**

정확 일치, 거친 행동 클래스 호환, 불일치와 UNKNOWN을 분리한다. 사람 행동은
정답이나 안전 기준이 아니며, 인과ㆍ우월성ㆍ학습 효과를 주장하지 않는다.

## 4. UPPAAL의 역할

UPPAAL은 영상 인식기, 최적 행동 선택기 또는 차량 안전 증명기가 아니다. 외부에서
주어진 CoC 계약 사건열을 상태기계로 재생하고 다음을 제공한다.

- 계약 의미론의 명시적 상태ㆍ전이 표현
- 안전성과 진행성 질의
- sticky 모순 플래그와 전체 사건 소비
- 최초 위반 상태와 사건의 반례 경로
- Python 구현과 독립적인 실행 의미론 교차검증

현재 모델은 장면별 결정적 관찰자이다. 가능한 모든 환경이나 행동 정책을 탐색하는
통합 제어 모델로 해석하지 않는다.

## 5. 자연 자료 검토의 수정

기존 `REVIEW_A.html`과 `REVIEW_B.html`은 실제 만족ㆍ해제 상태를 텍스트만으로
묻기 때문에 **사용 전 폐기 대상**이다. 답변 CSV는 생성되지 않았으므로 연구 판정에
사용된 결과는 없다.

대체 검토는 같은 블라인드 후보ㆍ대조군 표본 정책을 유지하되 다음만 묻는다.

- `obligation_explicit`: 지속 의무가 문장에 명시됐는가
- `required_action`: 문장이 요구하는 행동 클래스
- `persistence_explicit`: 의무의 지속이 명시됐는가
- `release_condition_explicit`: 해제 조건이 문장에 명시됐는가
- `ordered_steps_explicit`: 행동 단계 순서가 명시됐는가
- `textual_relation`: 후속 CoC가 앞 계약을 지지, 충돌, 불명확 중 무엇인가
- `state_evidence_needed`: 실제 상태 증거 없이는 판정할 수 없는가
- `evidence_sufficiency`: 텍스트만으로 위 항목을 판정하기 충분한가
- `confidence`, `notes`

검사기 결과, 후보ㆍ대조군, 실제 장면 ID는 계속 숨긴다. 검토자 일치도는 위 계약
구조 라벨에 대해서만 계산하며 실제 해제ㆍ안전의 사람 정답으로 부르지 않는다.

## 6. 남은 실험

1. 기존 검토 패킷을 `SUPERSEDED_BEFORE_REVIEW`로 표시하고 계약 구조 패킷 생성
2. 두 독립 검토 CSV가 없으면 `WAITING_FOR_CONTRACT_REVIEW`에서 중단
3. 궤적 부분집합에서 STOP/HOLD, DECELERATE/YIELD, MAINTAIN,
   ACCELERATE/PROCEED의 관측 행동을 보수적으로 추상화
4. 해제ㆍ객체 근거가 필요한 판정은 `UNKNOWN`
5. 자연 계약 구조, 통제 변형, 궤적 탐색 결과를 분리 집계
6. 기존 13개 장면 간 체인은 `PROVENANCE_POLICY_EXAMPLE`로만 평가
7. 실제 `verifyta`, 전체 시험, LaTeX 빌드와 SHA-256 manifest 확인

## 7. 주장 게이트

### 허용

- 통제된 계약 자료에서 상태형 검증이 사건별 검사보다 더 많은 연속 모순을 검출
- UPPAAL이 같은 의미론의 상태 전이와 반례를 제공
- 자연 CoC 텍스트의 계약 구조 명시성 및 증거 요구 정도
- 궤적 부분집합의 CoC 요구 행동–관측 행동 정합성에 대한 탐색 결과

### 조건부

- 자연 시간 모순의 수치는 계약 구조 검토에서 텍스트만으로 판정 가능하다고 합의된
  장면만 사용
- 20개 미만이면 자연 정량 주장을 하지 않고 기술 결과로 축소

### 금지

- 자연 자료 전체의 실제 상태 모순 발생률
- CoC 행동의 교통적 최적성 또는 규범적 허용성
- 사람 행동을 정답으로 사용한 성능 주장
- 통합 CoC 행동 모델 또는 폐루프 제어 강건성
- 물리 안전, 충돌 위험, 교통법규, 강화학습 성능 향상

## 8. 성공 기준

- 통제 쌍 40개와 네 유형별 10개 유지
- 정상 원본과 변형을 쌍 단위로 평가
- Python–UPPAAL 불일치가 없거나 모두 설명
- 계약 구조 검토에서 두 독립 원판정과 합의 기록 유지
- UNKNOWN과 `EVIDENCE_REQUIRED`를 오답으로 합치지 않음
- 자연ㆍ통제ㆍ궤적 결과를 서로 다른 표로 보고
- `claim_gate`가 금지한 문장을 논문과 초록에서 차단
- 원자료, 제한 CoC와 영상이 공개 경로로 복사되지 않음

## 9. 후속 연구

여러 CoC 시나리오를 Environment–CoC–Supervisor–Plant timed-automata network로
합성하고 adversarial 환경에서 강건성이나 제어 전략을 검증하는 연구는 별도 논문으로
남긴다. 이번 논문의 ContractMonitor는 그 후속 모델의 재사용 가능한 기반이다.
