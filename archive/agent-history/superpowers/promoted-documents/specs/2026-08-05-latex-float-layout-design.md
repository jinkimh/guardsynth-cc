# 국내 저널 원고 그림·표 배치 개선 설계

## 목적

두 단 전체 폭 그림과 표의 가독성을 유지하면서, float 배치 때문에 생기는 불필요한 페이지 공백을 줄인다. 본문 순서, 그림·표 번호, 인용 관계 및 논문 내용은 바꾸지 않는다.

## 확인된 원인

1. `sections/04-method.tex` 끝의 `\clearpage`가 대기 중인 float를 모두 내보낸 뒤 페이지를 강제로 끝낸다. 그 결과 7쪽 아래에 큰 공백이 생긴다.
2. `figure*`와 `table*`은 현재 두 단 문서에서 주로 다음 페이지 상단에 배치된다. 여러 개가 연속되면 본문과 float 사이의 이동 폭이 커진다.
3. `fig02_pipeline.png`는 도형이 사용하는 범위보다 세로 좌표 범위와 캔버스가 커서 그림 위·아래에 불필요한 여백이 생긴다. `fig05_typed_contract.png`에도 실제 도형 바깥의 투명 여백이 있다.
4. 현재 `\raggedbottom`은 4장과 5장에서 단 높이를 강제로 늘리지 않게 하므로 float가 이동한 페이지의 남은 공간이 그대로 드러난다. 그러나 이를 전역적으로 제거하면 문단 사이 간격이 부자연스럽게 늘어날 수 있다.

## 검토한 접근법

### A. 보수적 배치 개선 — 채택

- 4장 끝의 `\clearpage`를 제거한다.
- 넓은 그림과 표는 현재와 같이 `figure*`, `table*`로 유지한다.
- 그림 2는 생성 코드의 캔버스와 좌표 범위를 줄이고, 그림 7은 `\includegraphics`의 `trim`과 `clip`으로 필요한 만큼만 자른다.
- `[t]`를 `[!t]`로 바꾸고 float 사이 간격을 소폭 줄여 LaTeX가 상단 배치를 더 유연하게 수행하도록 한다.
- float 중심 정렬용 신축 여백을 제거해 그림·표 묶음을 페이지 상단에 맞춘다.
- 참고문헌 마지막 한 항목만 별도 페이지에 남으면 참고문헌만 9pt로 조정한다.
- 표·그림이 최초 인용보다 앞에 나타나지 않는지 확인한다.

장점은 논문 구조와 가독성을 거의 바꾸지 않는다는 것이다. 단점은 두 단 전체 폭 float의 기본 제약 때문에 모든 공백을 완전히 없앨 수는 없다는 것이다.

### B. 두 단 float의 하단 배치 허용 — 미채택

`dblfloatfix` 또는 `stfloats`를 사용해 `figure*`와 `table*`를 페이지 하단에도 놓는다. 공간 활용은 좋아질 수 있지만 국내 저널 양식이나 IEEE 계열 클래스와 충돌할 가능성이 있고, float 순서가 예상과 다르게 바뀔 수 있다.

### C. 넓은 그림·표 분할 — 미채택

일부 전체 폭 요소를 한 단 그림 또는 여러 표로 나눈다. 배치 자유도는 가장 높지만 글자 크기와 비교 가능성이 떨어지고, 그림·표 번호 및 본문 설명까지 크게 수정해야 한다.

## 적용 범위

- `main.tex`: float 묶음을 상단 정렬하고 참고문헌 크기를 조정한다.
- `sections/04-method.tex`: 강제 페이지 나눔을 제거하고 전체 폭 float 배치 옵션을 조정한다.
- `sections/01-introduction.tex`, `sections/05-experiments.tex`: 필요한 전체 폭 float에 동일한 배치 원칙을 적용한다.
- `figures/generate_figures.py`: 그림 2의 빈 세로 캔버스를 줄인다.
- `figures/test_generate_figures.py`: 그림 2의 세로 여백이 다시 커지지 않도록 종횡비를 검사한다.
- 그림 7의 `\includegraphics`: LaTeX 단계에서 내부 여백만 절단한다.

그림 데이터, 표 값, 캡션, 본문 내용은 변경하지 않는다.

## 검증 기준

1. 전체 원고가 오류 없이 빌드되어야 한다.
2. 미정의 참조·인용과 `Overfull` 경고가 없어야 한다.
3. 그림과 표의 글자가 기존과 같은 크기로 읽혀야 한다.
4. 기존 7–8쪽의 강제 페이지 종료 공백과 단 불균형이 제거되어야 한다.
5. 다른 페이지에 새로운 큰 공백이나 float 순서 역전이 생기지 않아야 한다.
6. 모든 그림·표는 관련 본문에서 처음 언급된 지점과 가깝게 유지되어야 한다.
7. 마지막 참고문헌 항목만 별도 페이지에 남지 않아야 한다.

## 비목표

- 페이지 수를 무조건 최소화하지 않는다.
- 표와 그림을 한 단 크기로 축소하지 않는다.
- 저널 클래스나 전체 타이포그래피를 교체하지 않는다.
- 논문 내용과 실험 결과를 수정하지 않는다.
