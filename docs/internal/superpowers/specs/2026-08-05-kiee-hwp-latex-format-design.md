# KIEE HWP 심사용 양식 기반 LaTeX 독립 복사본 설계

## 목적

`Template_File_for_Publication_심사+(2022).hwp`의 실제 지면과 작성 지침을 분석하여 현재 논문의 독립적인 LaTeX 심사용 복사본을 만든다. 기존 `latex-domestic/`의 `main.tex`, 절 파일, 그림 및 빌드 결과는 변경하지 않는다.

## 원본 HWP 분석 결과

HWP 5.x 복합 문서의 `FileHeader`, `DocInfo`, `BodyText/Section0`, `PrvText`, `PrvImage`를 읽어 다음 값을 확인하였다.

| 항목 | HWP에서 확인한 값 |
|---|---|
| 용지 | A4, 210 × 297 mm |
| 실제 문서 여백 | 왼쪽 18.01 mm, 오른쪽 18.01 mm, 위 18.99 mm, 아래 18.99 mm |
| 머리말·꼬리말 거리 | 각각 10 mm |
| 본문 단 구성 | 2단 |
| 단 사이 간격 | 8.0 mm |
| 본문 글꼴 | 조선일보명조 계열 |
| 본문 크기 | 약 8.5 pt |
| 본문 줄간격 | 150% |
| 절 제목 | 9 pt 굵게 |
| 하위 절 제목 | 8.5 pt 굵게 |
| 논문 제목 | 16 pt 굵게를 지침으로 명시 |
| 저자 | 12 pt 굵게를 지침으로 명시하나 심사용에서는 삭제 |
| 초록 | 영문 50–200단어, 수식·인용·각주 제외 |
| 키워드 | 영문, 보통 5–6개, 쉼표로 구분 |
| 그림 캡션 | 그림 아래에 한글과 영문 병기 |
| 표 캡션 | 표 위에 한글과 영문 병기 |
| 인용 | 대괄호 번호형, 문장부호보다 앞에 배치 |

HWP 본문의 설명에는 여백을 좌우 약 15 mm, 상하 약 25 mm로 적은 문장이 있으나, 실제 `PAGE_DEF` 레코드와 724 × 1024 미리보기의 지면은 약 18/19 mm를 사용한다. 새 LaTeX 양식은 설명문보다 실제 HWP 지면값을 우선한다.

## 선택한 접근법

`papers/paper1-safety-constrained-coc/latex-kiee-review-2022/`를 완전한 독립 복사본으로 만든다. 기존 절을 상대 경로로 참조하지 않고, 본문·그림·데이터·참고문헌·빌드 파일을 모두 새 폴더에 복사한다. 따라서 한 원고의 수정이 다른 원고에 자동으로 전파되지 않는다.

## 폴더 구조

```text
latex-kiee-review-2022/
├── main.tex
├── kiee-review.sty
├── references.bib
├── Makefile
├── README.md
├── sections/
├── figures/
└── fonts/
```

- `main.tex`: 익명 제목, 영문 Abstract, 영문 Key Words, 절 입력 및 참고문헌을 조립한다.
- `kiee-review.sty`: 용지, 여백, 글꼴, 단, 제목, 절, 캡션, 표 및 참고문헌 서식을 담당한다.
- `sections/`: 현재 논문의 한글 본문을 독립적으로 복사하고 한영 캡션을 반영한다.
- `figures/`: 현재 그림, 데이터, 생성 코드 및 검사를 독립적으로 복사한다.
- `fonts/`: SIL Open Font License의 `Noto Serif CJK KR` 글꼴과 라이선스 파일을 둔다.
- `README.md`: HWP에서 추출한 서식값, 빌드 방법, 글꼴 라이선스 및 원본 보존 방법을 설명한다.

## 첫 페이지 구성

첫 페이지는 HWP 순서를 따른다.

1. 16 pt 굵은 영문 제목
2. 14 pt 굵은 한글 제목
3. 저자·소속 없이 필요한 세로 간격만 유지
4. 8.5 pt 영문 `Abstract -`와 본문
5. 8.5 pt 영문 `Key Words :`
6. 이후 8 mm 간격의 2단 본문

HWP의 붉은 안내문은 작성 지침이므로 제출 원고에는 출력하지 않는다. 저자 각주와 소속도 심사용 복사본에는 넣지 않는다. 저작권 문구는 HWP와 같은 위치에 둘 수 있도록 스타일 명령을 제공하되, 심사용 기본값에서는 비활성화한다.

## 제목·초록·키워드

- 영문 제목은 한글 제목의 의미를 보존해 번역한다.
- 한글 제목은 현재 원고 제목을 유지한다.
- 현재 한글 요약을 근거로 50–200단어의 영문 Abstract를 새로 작성한다.
- 초록에는 식, 표·그림 번호, 인용 및 각주를 넣지 않는다.
- Key Words는 논문 핵심을 나타내는 영문 5–6개로 작성한다.
- 한글 요약은 새 심사용 복사본의 첫 페이지에서 제외한다.

## 본문과 수식

- 한글 본문과 실험 수치, 수식 및 인용의 의미는 변경하지 않는다.
- 본문은 `Noto Serif CJK KR` 8.5 pt를 사용하고 영문·숫자는 같은 계열 또는 호환되는 serif 글꼴을 사용한다.
- 기본 줄간격은 HWP의 150%에 대응하도록 설정한다.
- 절 제목은 9 pt 굵게, 하위 절 제목은 8.5 pt 굵게 설정한다.
- 번호 체계는 현재 논문의 절 구조를 유지하되 HWP와 같은 `1`, `1.1` 형식으로 출력한다.
- 수식은 중앙에 두고 번호는 오른쪽에 괄호로 표시한다.

## 그림과 표

- 그림 캡션은 그림 아래에 `그림 N ...`과 `Fig. N ...`을 차례로 둔다.
- 표 캡션은 표 위에 `표 N ...`과 `Table N ...`을 차례로 둔다.
- 기존 한글 캡션의 의미와 수치를 보존하여 영문을 추가한다.
- 그림·표가 한 단 너비에서 읽히지 않으면 현재와 같이 두 단 전체 폭을 유지한다.
- 글자 겹침, 잘림, 축 단위 누락 및 본문 최초 인용보다 앞선 배치를 검사한다.

## 참고문헌

- 참고문헌은 본문 인용 순서에 따른 대괄호 번호형으로 출력한다.
- 현재 `references.bib`의 항목은 유지한다.
- HWP 지침에 맞게 저자, 제목, 학술지·학회, 권·호·쪽·연도 순서를 확인한다.
- 참고문헌 제목은 `References`로 표시하며 영문으로 작성한다.

## 원본 보존

구현 전후에 다음 원본의 SHA-256을 비교한다.

- `latex-domestic/main.tex`
- `latex-domestic/sections/` 전체
- `latex-domestic/figures/` 전체
- `latex-domestic/references.bib`

새 양식은 이 경로에 쓰지 않는다. 빌드 부산물도 새 복사본 폴더 안에서만 생성한다.

## 검증 기준

1. 새 PDF가 XeLaTeX로 오류 없이 빌드되어야 한다.
2. 원본 `latex-domestic/`의 체크섬이 구현 전후 동일해야 한다.
3. 첫 페이지의 용지, 여백, 제목·초록 순서와 2단 시작 위치가 HWP 미리보기와 대응해야 한다.
4. 본문의 단 간격은 8 mm여야 한다.
5. 영문 Abstract는 50–200단어이고 식·인용·각주를 포함하지 않아야 한다.
6. 모든 그림·표 캡션은 한글·영문을 함께 표시해야 한다.
7. 미정의 참조·인용과 `Overfull` 오류가 없어야 한다.
8. 모든 페이지를 렌더링하여 표·그림 잘림, 큰 공백과 단 불균형을 확인해야 한다.
9. 글꼴 파일과 OFL 라이선스가 함께 있어 다른 시스템에서도 같은 모양으로 빌드되어야 한다.

## 비목표

- HWP 파일 자체를 수정하거나 새 HWP 파일을 생성하지 않는다.
- 연구 내용, 실험 결과와 결론을 다시 작성하지 않는다.
- 익명 심사용 복사본에 저자·소속·교신저자 정보를 넣지 않는다.
- 페이지 수를 맞추기 위해 본문이나 실험 결과를 삭제하지 않는다.
