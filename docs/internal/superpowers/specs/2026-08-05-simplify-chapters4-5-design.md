# 4–5장 설명 개선 설계

## 목표

4장과 5장의 연구 내용과 수치는 유지하면서, 처음 읽는 독자도 각 실험의 목적·구성·결과·의미를 한 번에 이해할 수 있도록 설명 순서를 고친다.

## 선택한 방식

세 가지 가능한 방식 가운데 전문 용어를 모두 없애는 방식이나 용어 해설만 덧붙이는 방식 대신, 기존 구조를 유지하면서 문단의 논리 순서를 다시 쓰는 방식을 사용한다. 각 개념과 실험은 다음 순서로 설명한다.

1. 왜 이 내용이 필요한가.
2. 무엇을 그대로 두고 무엇을 바꾸는가.
3. 간단한 예에서 정답이 어떻게 달라지는가.
4. 측정값이나 결과가 무엇을 뜻하는가.
5. 이 결과만으로 말할 수 없는 것은 무엇인가.

## 4장 편집 원칙

- 입력, 후보 선택, 독립 검증기의 역할을 순서대로 설명한다.
- 다섯 입력 조건은 이름보다 비교 이유를 먼저 이해할 수 있게 쓴다.
- 4.3절 첫 문단은 “한 장면으로 정답이 다른 두 문제를 만든다”는 설명으로 교체한다.
- 후보 문자 회전, 정답 생성, 평가 지표 및 실제 안전과의 차이를 짧은 예로 설명한다.

## 5장 편집 원칙

- 장의 첫 문단에서 실험들이 앞 실험의 한계를 어떻게 보완하는지 설명한다.
- 각 실험의 `확인 목적`, `비교 방법`, `결과`, `의미` 표시는 유지한다.
- 비교 방법에서는 바꾸는 변수와 고정하는 변수를 명시한다.
- 결과는 핵심 수치를 먼저 제시하고, 수치가 뜻하는 행동을 바로 이어서 설명한다.
- 통계적·실험적 한계는 삭제하지 않고 쉬운 문장으로 바꾼다.

## 유지할 내용

- 모든 표, 그림, 수치, 참조표시와 실험 조건
- 실제 차량 안전을 입증하지 않는다는 연구 범위
- 논리식 가드가 본질적으로 열등하다고 결론 내리지 않는다는 주의
- 세 번의 반복과 어려운 표현 평가에 관한 한계

## 검증

- LaTeX 전체 빌드가 성공해야 한다.
- 미정의 참조와 overfull box가 없어야 한다.
- 4–5장의 모든 소절을 다시 읽어 각 문단이 앞의 다섯 단계 중 맡은 역할을 분명히 갖는지 확인한다.
- PDF에서 표와 그림의 위치가 설명 흐름을 방해하지 않는지 확인한다.
