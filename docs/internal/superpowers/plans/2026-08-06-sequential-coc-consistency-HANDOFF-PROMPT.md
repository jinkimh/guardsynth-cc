## 연구 목적

동일 주행 클립 안에서 시간 순서대로 생성된 CoC를 지속되는 의무와 해제 조건으로
연결한다. 사건별 검사로는 찾기 어려운 미해소 의무, 조기 해제와 행동 충돌을
상태형 Python 및 UPPAAL로 검출할 수 있는지 평가한다.

주된 주장은 다음으로 제한한다.

> 미리 선언한 CoC 계약 의미론 아래에서 상태 기반 검증은 사건별 검사로 찾기
> 어려운 연속 CoC 모순을 검출하고, UPPAAL은 해당 모순의 상태 전이와 반례 경로를
> 제시할 수 있다.

보조 분석은 논리적 모순과 평가 가능한 궤적 계약 위반의 동반 여부이다. 실제
교통법규 위반, 충돌 위험, 물리적 차량 안전 또는 학습 성능 향상을 주장하지 마라.

위 값은 Task 1에서 원자료로 다시 계산하여 확인하라. 자동 선별 수치는 사람 정답이

기존 13개 장면 간 체인은 메타데이터 미러에 의존하고 공식 trainval 출처와 객체
연속성이 확인되지 않았다. 주된 검출 성능 자료로 사용하지 말고 출처ㆍ경계 정책의
보조 실험으로만 사용하라.

## 절대 준수 사항

1. 원천 데이터, 기존 결과와 현재 논문을 자동 실험이 끝나기 전에 수정하지 마라.
2. 새 코드는 `experiments/sequential_coc/`에 둔다.
3. 새 결과는 아래 제한 경로에만 둔다.

```text
artifacts/results/restricted/sequential-coc-consistency-v1/
```

4. 제한 CoC 원문과 영상은 공개 경로에 복사하지 마라.
5. 해제ㆍ객체 증거가 없으면 거짓으로 추정하지 말고 `UNKNOWN`으로 판정하라.
6. 자연 자료와 통제된 변형 자료를 별도로 보고하라.
7. 동일 장면의 여러 창과 원본ㆍ변형 쌍을 독립 표본으로 세지 마라.
8. 차선 변경은 현재 사례가 부족하므로 주 정량 주장에 넣지 마라.
9. 사람 판정 전에 검사기 결과나 원본/변형 여부를 검토 화면에 노출하지 마라.
10. 실험 결과가 성공 기준을 충족하기 전에는 논문의 결과 수치를 수정하지 마라.

## 실행 순서

1. 계획 Task 1의 재고와 기존 파일 해시를 고정한다.
2. TDD로 공통 계약 중간표현과 삼값 증거 의미론을 구현한다.
3. 94개 장면에서 장면 내부 사건 창을 추출한다.
4. 단계형 문장을 보존하는 보수적인 CoC 계약 컴파일러를 구현한다.
5. 사건별 기준선과 상태형 Python 검사기를 구현한다.
6. 동일 의미론의 UPPAAL 모델과 질의를 생성하고 Python과 동등성을 시험한다.
7. 네 모순 유형별 10쌍, 총 40쌍의 통제된 원본-변형 자료를 생성한다.
8. 정지ㆍ양보 후 진행 자연 후보와 대응 대조군의 블라인드 검토 HTML을 만든다.
9. 검토가 필요하면 자동 실행을 `WAITING_FOR_REVIEW` 상태로 멈추고, 사용자에게
   정확한 HTML 경로와 판정 항목을 안내하라. 검토 결과를 대신 만들어내지 마라.
10. 두 검토 CSV와 합의 결과가 준비되면 자연 자료, 변형 자료 및 궤적 자료를
    분리하여 평가한다.
11. `claim_gate`가 허용한 주장만 사용하여 KIEE 복사본을 수정한다.
12. 전체 시험, UPPAAL 실행, LaTeX 빌드와 SHA-256 manifest를 확인한다.

## 핵심 모순 유형

- `HOLD_GO_CONFLICT`: 유지 의무가 활성화된 동안 진행ㆍ가속 시작
- `PREMATURE_RELEASE`: 해제 조건이 거짓으로 확인됐는데 의무 해제
- `ORDER_VIOLATION`: 필수 정지ㆍ감속 단계 전에 다음 행동 시작
- `STALE_OBLIGATION`: 해제 조건 뒤에도 의무가 종료되지 않아 진행성 상실
- `UNSUPPORTED_CARRYOVER`: 출처 근거 없이 다음 장면으로 의무 이월; 보조 실험 전용

## 완료 보고 형식

각 작업 묶음이 끝날 때 다음을 보고하라.

- 변경한 파일
- 실행한 정확한 시험 명령과 결과
- 새로 생긴 결과 수치와 표본 단위
- 실패ㆍUNKNOWNㆍNOT_RUN 사유
- 다음 단계와 사람 검토 필요 여부

마지막 보고에는 다음을 포함하라.

- 자연 사건 창 수와 독립 장면 수
- 두 검토자 일치도와 UNKNOWN 수
- 모순 유형별 통제 변형 검출률과 정상 원본 오탐률
- 사건별 검사 대비 상태형 검사의 추가 검출
- Python-UPPAAL 판정 일치와 대표 반례
- 논리 판정과 궤적 계약 판정의 교차표
- 허용된 논문 주장과 금지된 주장
- KIEE PDF 경로, 페이지 수, 시험 결과와 SHA-256

작업 중 데이터 또는 도구가 부족하면 결과를 꾸미거나 범위를 몰래 바꾸지 말고,
계획의 중단ㆍ축소 기준에 따라 `UNKNOWN`, `NOT_RUN` 또는
`WAITING_FOR_REVIEW`로 기록하라.
