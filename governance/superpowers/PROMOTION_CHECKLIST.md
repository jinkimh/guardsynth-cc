# Superpowers document promotion checklist

Use this only when scratch work must become a durable repository document.

- [ ] The work has exactly one project/platform owner from `PROJECT_REGISTRY.json`.
- [ ] The target is exactly one approved document class.
- [ ] An existing canonical document cannot be updated instead.
- [ ] Task logs, review diffs, snapshots, hidden prompts, and duplicate plans were removed.
- [ ] Result claims link to immutable artifacts and retain their claim boundary.
- [ ] Local links resolve from the final target directory.
- [ ] The promotion is recorded in `PROMOTIONS.json`.
- [ ] `tests/structure/test_project_layout.py` passes.
