# KIEE 심사용 복사본 한국어 문장 편집 보고서

> 역사 기록: 이 문서는 최초 한국어 문장 편집 당시의 범위와 기준값을
> 기록한다. 현재 원고의 제목ㆍ초록ㆍ중심 실험 해석은 `README.md`와
> `main.tex`을 기준으로 하며, 아래의 보존 진술은 현재 원고 명세가 아니다.

## 수정 범위와 보존 범위

수정 대상은 `projects/03-sequential-coc-verification/paper/manuscript/latex-kiee-review-2022-coc-audit`의
한국어 제목, 10개 절의 한국어 본문, 표 안의 한국어 문구, 한국어 캡션과
두 TikZ 그림의 한국어 레이블이다. 원본 `projects/03-sequential-coc-verification/paper/manuscript`, KIEE 참조
양식과 참고문헌은 수정하지 않았다. 그림 자산 중 `overview-pipeline.tex`과
`training-routing.tex`은 사용자 승인에 따라 한국어 레이블만 고쳤으며, 나머지
세 그림과 스타일ㆍ글꼴ㆍ라이선스 자산은 수정하지 않았다.

자동 회귀 검사는 영문 제목, 154단어 영문 초록, 영문 핵심어 6개, 영문 캡션
23개가 기준값과 같은지 확인한다. 절별 숫자와 단위, 수식 원문, 인용, 레이블과
참조도 기준 JSON의 정렬된 다중집합으로 보호한다. 연구 질문 RQ1--RQ4의 의미,
실험 결과의 해석과 주장 경계는 자동 검사가 의미론적으로 증명한 항목이 아니다.
이 항목들은 원고와 편집 전 자료를 대조해 사람이 검토했다.

- 134개 후보는 서로 독립된 반응이나 에피소드가 아니다.
- 기본 결과의 분해는 `125+4+5`이다.
- 282개 모델과 1,128개 질의의 일치는 위반 여부 표시와 질의 변환 과정의
  회귀 시험 결과이다.
- 별도 구현의 13체인 결과는 기본 동작 확인에만 사용한다.
- 시간 조건은 반개구 조건 `r<D`이며 저장 집계에 정확히 `r=D`인 사례가 없다.
- 물리적 안전성, 일반적인 CoC 충실도와 학습 성능 향상을 입증하지 않는다.
- 상류 모델ㆍ데이터 버전과 공식 원본의 출처 한계를 유지한다.

## 대표 문장 10개의 정확한 편집 전ㆍ후 비교

아래 `전`은 편집 전 KIEE 복사본과 그 원본에 있던 문구이며, `후`는 최종
KIEE 복사본의 문구이다.

### 1. 한국어 제목

전:

```tex
\kieekoreantitle{추론 보강형 E2E 자율주행 데이터의 시간·출처 계약 감사: CoC-Nusc와 UPPAAL 기반 분석}
```

후:

```tex
\kieekoreantitle{추론 보강형 E2E 자율주행 데이터의 시간ㆍ출처 계약 검증: CoC-Nusc와 UPPAAL 기반 분석}
```

### 2. 서론의 핵심 문제

전:

```text
저장된 시점별 CoC 주석과 자차 움직임을 하나의 학습 시퀀스로 조합할 때, 반복 주석, 후보 기한, 응답 계보, 장면 출처 정책을 어떻게 명시하고 감사할 것인가가 남는 문제이다.
```

후:

```text
첫째, 같은 행동 의도를 나타내는 CoC가 여러 번 기록되었을 때 어느 사건부터 반응 시간을 계산할지 정해야 한다. 둘째, 관측된 차량 반응이 어느 CoC 사건에 대응하는지 연결 관계를 확인해야 한다. 셋째, 출처 근거가 없는 서로 다른 장면을 하나의 시퀀스로 연결하지 않도록 장면 출처 정책을 확인해야 한다.
```

### 3. 관련 연구에서 본 연구의 위치

전:

```text
본 논문의 단위는 모델 출력의 재평가가 아니라 저장 주석 감사이다.
```

후:

```text
본 논문은 모델 출력을 다시 평가하지 않고 저장된 CoC 데이터를 검증한다.
```

### 4. 사후에 추가한 임시 규칙

전:

```text
이 $0.5$~m/s 임계값은 요구사항에서 독립적으로 도출한 값이 아니라 해당 코호트에 맞춘 탐색적 보정 논리이다.
```

후:

```text
이 $0.5$~m/s 임계값은 요구사항에서 독립적으로 도출한 안전 기준이 아니다. 현재 분석 대상의 결과에 맞춰 사후에 추가한 탐색 규칙이므로, 다른 자료에서 별도로 검증해야 한다.
```

### 5. 방법 절의 입력과 처리

전:

```text
방법은 문제 정의의 세 증거 층---주석에서 파싱한 행동 의도, 연구자가 선택한 후보 시간 계약, 자차 움직임에서 도출한 응답 증거---을 다음 네 구성요소로 연결한다.
```

후:

```text
입력은 CoC에서 읽은 행동 의도와 발생 시점, 차량 속도 기록, 장면 출처 정보이다. 처리 과정에는 연구자가 선택한 잠정 제한 시간과 반복 CoC 처리 정책이 들어간다. 출력은 설정한 조건의 충족 여부와 추가 검토 경로이다.
```

### 6. 플래그와 질의 변환 시험의 범위

전:

```text
기대 판정도 같은 레이블에서 도출되므로 이는 관찰자 수준 시간 변이 검증이 아니라 플래그/질의 직렬화 회귀이다.
```

후:

```text
기대 판정도 같은 레이블에서 만들기 때문에 이 일치는 시간 검증 성능이 아니다. 관찰자 수준 시간 오류를 구분했다는 근거도 아니며, 그 근거는 \texttt{scene-0001} 모델에 한정한다.
```

### 7. 별도 구현의 13체인 결과

전:

```text
복합 의도는 감속으로 오분류될 수 있으므로 이 수는 \texttt{LoopSource}/\texttt{Monitor} 구현 파이프라인의 기술적 스모크 출력이지 RQ3의 정량 결과가 아니다.
```

후:

```text
따라서 이 수치는 \texttt{LoopSource}/\texttt{Monitor}라는 별도 구현이 실행되는지만 확인한 기본 동작 결과이다. RQ3의 성능 수치로 사용할 수 없다.
```

### 9. 측정 타당성의 탐지기 한계

전:

```text
응답은 액추에이터 명령이 아니라 자차 궤적에서 계산한 속도 변화 대리변수이다. 창 $W$, 속도 임계값 $\delta$, 방향 비율 $\rho$에 따라 판정이 달라질 수 있고, 27개 설정도 모든 유효 탐지기를 포괄하지 않는다.
```

후:

```text
차량 반응은 액추에이터 명령이 아니라 자차 궤적에서 계산한 속도 변화 대리변수이다. 판정은 창 $W$, 속도 임계값 $\delta$, 방향 비율 $\rho$에 따라 달라질 수 있다. 27개 설정도 가능한 모든 탐지 방법을 포괄하지 않는다. 따라서 현재 결과만으로 다른 반응 탐지 방법에서도 같은 분류가 나온다고 결론 내릴 수 없다. 후속 연구에서는 독립적인 반응 주석을 기준으로 탐지 방법을 검증해야 한다.
```

### 10. 결론의 목적과 방법

전:

```text
추론 보강형 E2E 주행 데이터는 행동 이유를 제공하지만, 반복 CoC 사건이 언제 후보 의무를 열고 자차 움직임 응답이 언제 이를 닫는지, 그리고 그 연결이 어떤 출처에 근거하는지는 별도 감사가 필요하다. 본 논문은 시점이 있는 CoC 주석, 도출 자차 움직임 응답, 반복ㆍ기한 정책과 장면 출처를 \uppaal 시간 관찰자 네트워크로 컴파일하여 저장된 사건열의 시간ㆍ출처 계약을 검사하는 방법을 제안하였다.
```

후:

```text
추론 보강형 E2E 주행 데이터는 행동의 이유를 제공하지만 그 자체로 차량 반응과의 시간 관계나 장면 출처를 보장하지 않는다. 특히 같은 행동 의도의 CoC가 반복될 때 어느 사건부터 반응 시간을 계산할지 정해야 하며, 관측한 차량 반응이 어느 CoC와 연결되는지도 확인해야 한다. 본 논문은 시점이 기록된 CoC 주석, 차량 움직임에서 찾은 반응, 반복 CoC 처리 정책, 잠정 제한 시간 및 장면 출처를 \uppaal 시간 관찰자 네트워크로 변환했다. 이를 통해 저장된 사건열이 시간ㆍ출처 검증 조건을 충족하는지 확인하는 방법을 제안하였다.
```

## 최종 검토 수정

최종 독립 검토에서 중요 항목으로 분류된 지적을 다음과 같이 반영했다.

- 데이터 출처 설명에서 조건 설정 주체를 모델이 아니라 `본 연구`로 바로잡고,
  134건을 `방향 명시 CoC 사건별 검증 후보`로 통일했다.
- `후보 기한`, `의무 생성`, `응답 증거`를 각각 `잠정 제한 시간`,
  `검증 항목 생성`, `차량 반응`으로 고쳤다. 학습 전 처리 표와 그림에는
  `반복 처리 정책ㆍ잠정 제한 시간ㆍ탐지기 설정`을 함께 명시했다.
- 초기 8건은 실패가 아니라 검토 후보였음을 밝히고, 그중 3건을 사후 규칙으로
  재분류했으며 이 규칙을 독립 자료로 검증하지 않았다는 한계를 유지했다.
- RQ3를 장면 연속성 근거와 경계 정책이 장기 시퀀스 연결을 어떻게 제한하는지
  직접 묻는 문장으로 고쳤다. 상태 관찰자와 결과 분류기는 중복 이름 없이 각
  역할을 먼저 설명하도록 정리했다.
- 인과 근거를 확인할 수 없다는 한계, 4/9와 8/7/0의 개별 의미, 선택 사례에만
  적용한 반응 대기 상태의 \preserve/\reset 분석을 명시했다.
- `긴 꼬리`는 `희귀 주행 상황에 대한 일반화`로 풀었고, AI 검토는
  `AI를 이용한 시각적 1차 선별`로 한정했다. 중복 제거 오류는 CoC 사건을
  제거하면서 연결된 차량 반응을 함께 제거하거나 다시 연결하지 않은 과정부터
  설명한 뒤 코드 식별자 \texttt{orphan\_response}를 제시했다.

`1차`의 `1`은 연구 결과값이 아니라 최종 검토가 요구한 자연어 서수이다. 이
승인된 어휘 토큰을 기준 JSON에 기록했으며, 기존 연구 수치ㆍ단위ㆍ수식ㆍ인용ㆍ
레이블ㆍ참조의 다중집합은 그대로 보존했다.

## 검증 결과

`make -C projects/03-sequential-coc-verification/paper/manuscript/latex-kiee-review-2022-coc-audit test`를 실행해
형식 검사 12개와 편집 무결성 검사 9개, 모두 21개가 통과했다. 이 검사에는
영문 전면 요소, 영문 캡션, 절별 수치ㆍ단위ㆍ수식ㆍ인용ㆍ레이블ㆍ참조,
비본문 자산, 원본과 참조 양식의 해시 검사가 포함된다. 사용자 승인으로 고친
두 그림은 아래 새 해시를 기준값에 반영했고, 다른 자산은 기존 해시를
보존했다. `main.tex`에서 `\input`을 재귀적으로 따라간 16개 TeX 입력 전체에서
검사에 열거한 구표현은 0건이었고, `라우팅`, `코호트`, `감사`의 수동 검토
보고 위치도 0건이었다. 이는 열거한 잔여어에 대한 회귀 검사와 최종 수동 검토
결과이지, 모든 한국어 문장의 품질을 자동으로 증명한다는 뜻은 아니다.

기존 형식 검사의 `REQUIRED_SCOPE`에는 한국어 `스모크`가 반드시 남아 있어야
한다는 낡은 기대값이 있었다. 승인된 용어 계획은 이 표현을 `기본 동작`으로
바꾸도록 요구하므로, 다른 범위 검사에는 손대지 않고 이 한 항목만
`기본 동작`으로 교정했다. 별도 구현 결과를 성능 근거로 확대하지 않는다는
검사의 목적은 그대로 유지된다.

## 그림 레이블 수정과 자산 해시

개요 그림의 마지막 상자는 다음처럼 바꿨다.

```text
전: 감사 라우팅 / 약한 유지 후보ㆍ검토 후보 / 출처 불충분
후: 검증 결과별 처리 / 유지 검토ㆍ추가 확인 / 긴 연결 제외ㆍ회귀 시험
```

학습 전 처리 그림의 네 분기는 본문과 표의 네 동작을 그대로 요약한다.

```text
전: 원천ㆍ품질ㆍ계약 근거 유지 / 약한 유지 후보
후: 설정한 조건 안에서 반응 확인 / 근거 확인 뒤 유지 여부 검토

전: 정책ㆍ기한ㆍ탐지기 민감 / 검토 후보
후: 정책ㆍ기한ㆍ탐지기에 따라 변경 / 사람이 추가 확인

전: 응답 계보ㆍ연속성 근거 없음 / 출처 불충분
후: CoC--반응 연결ㆍ장면 출처 부족 / 긴 시퀀스로 연결하지 않음

전: 알려진 합성 변이 / 검사기 회귀 시험 전용
후: 인위적 오류 사례 / 검사기 회귀 시험에만 사용
```

상자 위치, 너비, 연결선과 분기 의미는 바꾸지 않았다. 문구는 각 상자에서
두세 줄 안에 들어가도록 줄였으며, 성능 판정이나 안전 레이블로 읽히지 않게
후속 동작을 동사형으로 썼다.

## 주장 변경 금지 경계

이번 작업은 문장의 순서와 표현만 고쳤다. 새로운 실험 결과, 안전성 주장,
인과성 주장 또는 일반화 주장을 추가하지 않았다. 설정한 조건 안에서 반응이
확인되었다는 결과는 물리적 안전을 뜻하지 않으며, 추가 검토 대상은 실제
위험이나 결함으로 확정된 사례가 아니다. 인위적 오류 사례는 검사기 회귀
시험에만 사용하고, 출처 근거가 부족한 장면은 장기 학습 시퀀스로 연결하지
않는다는 경계를 유지했다.

## 최종 빌드와 전 페이지 시각 검토

최종 `make all`은 형식 검사 12개와 편집 무결성 검사 9개를 합한 21개를
모두 통과한 뒤 LuaLaTeX--BibTeX--LuaLaTeX--LuaLaTeX 빌드를 종료 코드
0으로 마쳤다. 최종 수정 뒤 결과물 `main.pdf`는 16쪽, 394,983바이트이며
SHA-256은
`ac104de12dfde08c272a2d890d2302e20e4a768494ed8ce6166eac25d33380f8`이다.
최종 `main.log`에서 정의되지 않은 명령, 정의되지 않은 인용ㆍ참조, 치명적
오류, 비상 정지, overfull 상자와 누락 문자를 찾는 차단 검색 결과는 0줄이다.

첫 전체 빌드는 `sections/07-results.tex`의 `\preserve가`에서 중단되었다.
LuaTeX가 영문 매크로 뒤의 한글 조사를 같은 제어어로 읽은 것이 원인이었다.
전체 입력을 같은 패턴으로 검사해 `\preserve와`, `\reset에`를 각각
`\preserve{}과`, `\reset{}에`로 분리했다. 7절에서는 첫 수정 때
`\preserve가`를 `\preserve{}가`로 분리했으나, 이는 `보존가`로 출력되는
잘못된 조사 선택이었다. 검토 1차에서 이를 `\preserve{}이`로 바로잡아
`보존이 유일하게 올바른 방식이라는 뜻도 아니다`로 출력되게 했다. 이는
앞선 보고서의 부정확한 `출력 의미를 바꾸지 않는 조판 수정` 설명을
정정하는 한국어 문법 교정이다. 기술적 주장, 수치ㆍ수식ㆍ인용ㆍ영문 요소와
주장 범위는 바뀌지 않았고 편집 무결성 검사에서 다시 기준값과 일치했다.

`mutool draw -r 180`으로 최종 PDF 16쪽 모두를 PNG로 다시 렌더링하고
페이지별 검토했다. 영문ㆍ한국어 제목, 두 열 본문, 절 제목, 수식, 목록,
표 1--18, 그림 1--5와 이중언어 캡션, 참고문헌을 확인했다. 특히 2쪽의
`overview-pipeline`과 13쪽의 `training-routing`에서 고친 한국어 레이블은
상자 안에 들어가며 선이나 다른 글자와 겹치지 않았다. 최종 검토에서는
13쪽을 원본 해상도로도 확인했고, 길어진 설정 문구가 네 줄로 자연스럽게
배치되었다. 글자 겹침ㆍ잘림,
깨진 글리프, 중간 페이지의 빈 열, 고립된 절 제목과 가독성을 해치는 큰
공백은 없었다. 16쪽 오른쪽 열의 여백은 참고문헌이 왼쪽 열에서 끝난 종결
페이지의 정상 여백이다.

검토 1차에서는 영향 페이지인 11쪽을 180 dpi로 다시 렌더링해 원본
해상도로 확인했다. 고친 문장은 오른쪽 열 아래쪽에서 자연스럽게 줄이 바뀌며,
표 11--13, 두 열 배치와 전체 16쪽 구성은 유지되었다. 텍스트 추출에서도
`보존이 유일하게 올바른 방식이라는 뜻도 아니다`를 확인했다.

로그에는 두 열 한글ㆍ고정폭 영문ㆍ참고문헌 조판에서 생긴 underfull 상자
165건과 설치된 글꼴에 없는 이탤릭ㆍ스몰캡ㆍ일부 수학 글꼴 크기의 대체

나타나지 않음을 확인했으므로 레이아웃 차단 사항으로 보지 않았다.

원본 매니페스트 24개와 참조 양식 매니페스트 43개는 모두 `OK`였다. 편집 기준
