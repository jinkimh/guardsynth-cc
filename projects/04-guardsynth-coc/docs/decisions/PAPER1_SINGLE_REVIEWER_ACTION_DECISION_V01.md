# 1차 논문 행동 판단의 단일 검토자 기준

- project_id: `guardsynth-coc`
- 결정일: 2026-09-29
- 상태: `ACCEPTED_FOR_PAPER1_ACTION_REFERENCE`
- 근거: 사용자가 “비교적 단순 설문이기 때문에 1인 판단으로 충분해 보임”이라고 판단했다.
- 상위 기준: [연구계획](../plans/01_RESEARCH_PLAN_V02.md)
- 적용 단계: [M16·M17](../plans/02_PROJECT_MILESTONES.md)의 1차 논문 행동 적절성 응답

## 결정

현재 네 가지 속도 행동의 적절성 설문에는 **검토자 1명의 판단을 행동 참조값으로 수용**한다.
동일 ACTION에 두 번째 검토자나 제3자 합의를 요구하지 않는다. 이는 제한된 1차 연구의
평가 프로토콜 선택이며, 질문이 단순하므로 오류가 없거나 1인의 판단만으로 안전성을
증명한다는 결론은 아니다. 논문에서는 `single-reviewer action reference`라고 명시한다.

Jonh의 기존 19장면/76판단과 사용자 추가 설명을 재사용한다. 원답·이름·비노출 자기진술의
출처·판단 불가·세 항목의 의미 범위 제한을 그대로 보존하며, 이미 수용한 ACTION을 다시
수집하지 않는다. 현재 19건에 대해서 검토자 수 요건은 충족됐다. 72개 확정 비제한 필드는
평가 가능한 개발 응답 수이지 72개 장면 또는 학습 적격 수가 아니다.

같은 제한된 ACTION 과제로 추후 별도 미노출 평가 장면을 구축할 때도 1인 참조값을 사용할
수 있다. 다만 현재 19장면은 이미 노출된 개발 집합이며 새 test로 옮기지 않는다. ACTION
먼저, CNL/원문/기계 제안 노출은 나중이라는 순서는 유지한다. 검토자가 이미 본 자료를
독립 미노출 평가로 재분류하지 않는다.

## 제거하는 종료 장애물과 유지하는 조건

- 이 ACTION 범위에 한해 두 reviewer·제3자 adjudication·검토자 간 α 기준을 종료 조건으로
  사용하지 않는다. 검토자 간 일치도/신뢰도는 `NOT_MEASURED_SINGLE_REVIEWER`로 보고한다.
- 다수 전문가 합의 gold, 객관적 무오류 정답, 일반적 운전자 판단이나 실차 안전성을 주장하지 않는다.
- 단일 검토자의 판단 편향과 복합 선택지 해석 한계를 논문에 명시한다. 통계적 표본 변동의
  구간 추정이 검토자 편향까지 측정한다고 주장하지 않는다.
- 원본 CoC와 응답의 불일치는 남긴다. 기존 기준에 맞지 않는 항목은 이유와 처리 범위를
  기록하며, 오류를 감추기 위한 자동 재라벨·유리한 장면 선별·기계의 가상 2인 판정을 하지 않는다.
- source/대상/시간/규칙 적용성, UNKNOWN 보존, EBLC 실행 검증, CNL 의미 확인,
  고정된 train/dev/test와 노출 이력, 충분한 표본 및 동일 학습 예산은 별개로 유지한다.
- ACTION 판단을 제약 생성 근거로 역이용하지 않는다. 단일 검토자 기준 수용만으로
  source 부재·CNL 미검토를 채우거나 본 학습 적격성을 자동 확정하지 않는다.

## 역사 및 소유 범위

기존 strict60·2차 실제 적용·별도 source/guard-type 전문가 프로토콜의 2인 기준은 변경하지
않는다. 이전 run의 `formal_two_reviewer_gate_met: false`는 당시 엄격 기준의 사실로 남기되,
현재 1차 ACTION을 막는 조건으로 재사용하지 않는다. 과거 제출·명세·시험 결과는 수정하지 않는다.
이 결정은 1차 ACTION 검토자 수만 바꾸며, M16 전체나 M17 전체 완료 선언은 아니다.

계획·마일스톤·추적표의 현재 상태에서 이 범위와 역사적 2인 gate를 구분한다. 이미 받은
19건을 반복하지 않고 기존 근거 기반 속도 제약 연결 작업을 계속한다.
