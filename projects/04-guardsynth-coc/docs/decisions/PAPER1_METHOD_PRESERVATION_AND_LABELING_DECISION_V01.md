## 1. 사용자 결정과 적용 범위

> 이 논문에서는 우리의 방법에 대한 전반적인 소개 및 기존의 개선을 최대한 보존하는 방식으로 진행하자...
> 만약 더 많은 데이터를 만들어야 한다면 사람의 표본 감사와 독립에 집중하되 최대한 LLM을 사용하여 레이블링 하도록 하자..

1차 논문은 CoC/장면/근거 → 제약 후보 → EBLC 명세·검증 → 의미 보존 CNL → VLM 학습의
방법 소개와 **기존 제약의 학습 효과 보존**을 중심으로 한다. 효과 보존은 가설이지 보장된 결과가 아니다.
전수 사람 승인·새 실제 영상 본 학습 자료 확보를 이 논문의 일괄 선행조건으로 두지 않는다.
기존 통제 합성 시각 과제를 재사용한 실제 VLM 학습/행동 평가를 우선하고 실제 도로 영상은
기존 검토를 재사용한 제한적 적용 사례로 분리한다. 합성 자료를 실제 도로 근거로 승격하지 않는다.
반자동 실행은 허용하나 수작업 제약 선택을 자동 추출 성과로 쓰지 않는다.

## 2. 주 비교와 주장

### 2026-09-29 결과 열람 후 보고 방침 개정

사용자 명시적 요청: “모든 시드 20%이상은 너무 엄격해.. 얼마나 향상되던 모두 결과로 넣자..”

이 결정은 확장 실험 결과를 열람한 뒤 정한 **보고 방침 변경**이다. 모든 시드에서20%p 이상 개선을
논문 결과 포함이나 연구 진행의 필수 조건으로 사용하지 않는다. 향상 크기와 무관하게 모든 사전
계획 조건·시드·평가 묶음을 보고하며, 무개선·저하·불확정·실패도 누락하지 않는다.
본문은 핵심 비교를 요약하고 전체 조건별/시드별 수치는 보충자료 또는 연결된 결과표에 제공한다.
절대 성능, 기준 대비 percentage-point 차이, 시드 간 변동, 적절한 단위의 paired 불확실성 구간,
표본/합성 과제 한계를 함께 보고한다. 작은 양의 점추정치를 통계적 우월성이나 동등성으로 바꾸지 않는다.

기존 frozen protocol/config, 원예측·checkpoint, RESULT와 기존 판정은 변경하지 않는다.
`temporal-expansion-learning-2026-09-29-001`의 원판정 `NOT_SUPPORTED`는 고정된 전체 point criteria
미충족을 뜻하며 학습 실행 실패나 개선 부재를 뜻하지 않는다. 사후 문턱을 골라 이 판정을
`SUPPORTED`로 재계산하지 않는다. 기존20%p 기준과 미충족 사실은 방법/한계 또는 보충자료에 남긴다.
효과 보존과 성능 향상은 별도 비교로 기술하며, 이 개정은 과거 또는 진행 중인 비용 학습의
수치 판정 기준·모델 선택·학습 예산·데이터 분할을 변경하는 승인이 아니다.
이하 사전 기준 요구는 실행 재현성 기록으로 유지하되, 결과 공개의 gate로 해석하지 않는다.

### 사용자 후속 명확화: 검증의 기여는 제약 품질

사용자는 EBLC 정형 명세를 행동 테스트에도 사용할 것을 명확히 했다. 따라서 EBLC의 역할은
학습 전 명세 검증과 CNL 생성에 한정되지 않는다. 모델이 선택한 후보 행동을 실행 변수에 연결해
제약 준수·위반·판정 불가를 구분하고, 독립 환경/관찰 근거와의 대조를 유지한다. 계속 정지하는
행동의 제약 준수를 정상 진행 성공으로 대신하지 않으며, 평가 행동 정답을 모델 입력으로 제공하지 않는다.

> 검증 때문에 모델 성능이 좋아질 것은 기대하지 않아...검증으로 인해 CoC 자체 내에 품질에 대해서는 주장할 수 있지..

주장은 두 축으로 분리한다. 모델 비교는 정형화·검증·CNL 전달 경로에서도 기존 제약의 학습 효과가
유지되는지를 평가하며, 검증 자체의 추가 성능 향상을 요구하지 않는다. 검증 실험은 CoC에 삽입하는
제약의 지원 범위 내 논리적 일관성, 명시된 근거와의 대응, EBLC→CNL 의미 보존과 오류 차단을 평가한다.
이는 CoC 전체의 영상 해석·추론 사실성·안전성을 인증하는 주장이 아니다. 근거 대응과 의미 보존도
SAT 성공만으로 입증하지 않고 해당 독립 대조 검사로 뒷받침한다. 오류 주입 시험의 탐지율·미탐률·
정상 제약 오탐률·수용률은 지원한 오류 유형에 한정하며 실제 생성 CoC의 자연 발생 오류율과 구별한다.
검증 전후 품질 비교는 동일한 후보 집합으로 수행하며 전부 거부해서 얻은 품질 개선을 성공으로 세지 않는다.

### 사용자 후속 명확화: 기존 논문이 지지한 개선 수준

> 기존의 학습 효과 유지라 함은 이전에 우리의 논문에서 지지하던 그 수준은 보여줘야 한다는 의미야

‘보존’은 의미 변환/실행 성공 또는 임의로 낮아진 P1과 비슷하다는 뜻이 아니다. 기존 논문의
위반 감소와 목표 진행 유지 수준을 비교 기준으로 두고, P1의 기존 효과 재현과 P2의 개선 수준을
함께 확인한다. P1/P2가 함께 낮은 성능을 보여도 비슷하다는 이유만으로 보존 성공으로 판정하지 않는다.
[선행 temporal 보고서](../../../01-safety-constrained-coc/docs/reports/TEMPORAL_GUARD_MULTISEED_EXPERIMENT_REPORT_V01.md)의
표준 조건 3-seed 평균은 원본 위반0.319/제약0.000, 제약 준수 목표 완료0.681/1.000이다.
이는 해당 합성 과제/조건의 역사적 기준이지 새 장면의 보장값이나 보편적인100% 목표가 아니다.
unseen-time에서 제약 준수 목표 완료0.625/0.649였던 한계도 함께 보존한다.
새 결과 전 기존 조건 대응표, P1 재현 기준, P2-P0 개선 및 P2-P1 허용 열화 기준을 고정한다.
기존 수준이 재현되지 않으면 원인/한계와 NOT_SUPPORTED 또는 INCONCLUSIVE를 보고하며
방법 소개만으로 사용자가 요구한 학습 효과 증거를 충족했다고 쓰지 않는다.

새 protocol ID는 `paper1-method-preservation-v0.1`이다. 기존 L0–L3 run/설정을 재표기하지 않는다.

| 새 조건 | 내용 | 역할 |
|---|---|---|
| P0 | 원본 CoC, 제약 없음 | 제약 없는 기준 |
| P1 | 기존 방식의 올바른 자연어 제약 + CoC | 보존할 기존 개선 |
| P2 | 같은 의미의 제약을 EBLC로 명세·검증하고 생성한 CNL + CoC | 이번 전달 경로의 효과 보존 |

장면·후보·행동 정답·초기 모델·seed·학습 예산을 맞춘다. P1/P2는 학습과 평가에서 제약의
제공 위치·가시성을 맞춘다. 기존 실험처럼 평가 시 적용 계약을 입력으로 제공하는 통제 과제를
허용하되, 평가 행동 정답으로 계약을 역생성하거나 정답 후보를 입력하지 않는다. P0의 정보 부재는
의도된 기준선 한계로 명시한다. 새 제약 미제공 일반화 평가는 별도 후속 질문이지 주 비교와 혼합하지 않는다.
실제 도로에서는 모델/파이프라인이 생성한 제약과 사람이 제공한 제약을 구별한다.

실행 전 데이터/분할/renderer/checkpoint/입출력 형식/예산/지표를 고정하고 최소 3 paired seeds를
계획한다. 독립 장면 수·seed 수·위반률·정상 진행/불필요 정지·coverage·불확실성을 함께 보고한다.
형식적 비열등성 주장을 하려면 허용 열화폭과 분석을 새 결과 열람 전에 정한다. 기한 때문에 표본이나
반복이 부족하면 탐색적/불확정으로 보고하며 사후 성공 기준을 고르지 않는다.
P2 대 P1의 효과 보존과 P2 대 P0의 개선을 분리한다. 비유의한 차이는 동등성 증명이 아니다.
직접 생성/검증 생략 대조는 검증의 추가 기여를 주장할 때 필요하며, 이전 네-arm 본 실험을 완료한
것으로 처리하지 않는다. 형식 검증/주입 오류 검사는 행동 학습 효과와 별도 증거다.

Project01 코드·원 결과는 출처를 붙여 재사용하고 원본을 변경하지 않는다. 기존 test가 개발에 노출된
재사용 benchmark임을 공개하고, 새 효과 확인에는 사전 고정한 미사용 생성 seed/장면을 둔다.
이전 성능 수치를 새 P2 결과로 복사하지 않는다. 출력/학습 자료가 byte-identical이면 그 사실과
기존 결과 재사용을 명시하며 새 독립 학습 run이나 새로운 효과 입증으로 세지 않는다.

## 3. LLM 라벨링과 사람 역할

데이터가 더 필요할 때 로컬 LLM/VLM·기존 주석·프로그램을 최대한 사용해 학습 초안을 만든다.
시각 근거가 필요한 항목은 실제 프레임을 보는 VLM 또는 출처가 고정된 주석을 사용한다.
LLM 문장만으로 영상 관측 사실을 만들지 않는다. 각 행에 원자료/시점, 모델/revision, prompt,
raw 응답, 변환/검증 결과, 불확실성, 검토 출처를 기록한다. 기계 라벨은 `LLM_WEAK_LABEL`로
분리하며 `HUMAN_REVIEWED` 또는 실제 도로 gold로 표시하지 않는다. 동일 clip 파생 자료는 같은 split이다.

사람은 무작위/행동군별 표본 감사와 불일치·미지원·고위험 사례 확인에 집중한다. 어려운 사례만
검토한 결과를 전체 오류율로 쓰지 않는다. 표본 추출 seed·크기·층·확대/보류 기준을 결과 전에
고정하고, 중대한 오류가 나오면 해당 template/batch를 수정·재감사하거나 보류한다.
표본 감사 허용은 미검토 배치의 무조건 수용이 아니다. 기존 개별 승인과 실제 관찰은 보존한다.

평가 참조는 학습용 LLM/EBLC 출력과 분리한다. 합성 과제는 독립 구현한 환경 규칙/행동 evaluator와
반례·mutation·교차 검사를 사용하고 공유 가정을 공개한다. 실제 영상 평가는 생성 제약/모델 예측에
영향받지 않은 사람 참조를 사용한다. 생성 LLM이 자기 라벨을 다시 채점한 일치율을 독립 성능으로
제시하지 않는다. 학습 모델·정답 정보의 test 누출을 검사하며 SAT는 관측 사실의 진실성을 보증하지 않는다.

## 4. 기존 계획과 실행 경계

이 결정은 충돌하는 v2.3의 실제 영상 본 학습 필수, 전수 인간 CNL 승인, supervision-only/no-guard-at-test,
네-arm 모두 완료 및 C1–C4 전체 우월성 입증을 이번 소개 논문의 일괄 종료조건에서 분리한다.
그 과제를 성공/완료로 바꾸지 않고 후속 확장으로 보존한다. 원 strict60·노출 원장·19 ACTION·3 masks·
두 STOP 수용·이전 실패 결과와 immutable runs는 그대로다. 기존 소비자의 gate는 별도 정책 연결과
회귀 검증 전 자동 완화하지 않는다. 새 약지도 경로는 기존 사람 승인 데이터와 구별한다.

M16=재사용/표본 감사·독립 참조, M17=분할·EBLC/CNL 의미 보존·비교 자료, M18=효과 보존 비교,
M20=방법 소개/실제 결과/한계/재현 패키지. 문서 개정만으로 어느 마일스톤도 완료하지 않는다.
실제 VLM 가중치 업데이트와 시각 입력 행동 평가 요구는 유지한다. 원고 작성은 결과 수집과 병행한다.
Alpamayo 전환·실차·유료 API·외부 데이터 업로드·다른 사용자의 GPU 작업 중단은 승인하지 않는다.
