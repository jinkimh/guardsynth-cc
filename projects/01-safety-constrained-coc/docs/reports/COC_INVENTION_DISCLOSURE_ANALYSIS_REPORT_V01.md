## 1. 종합 판단

이 문서는 논문의 중심 아이디어를 **실행 가드가 반영된 정답 생성과 모델 학습 방법**으로 재구성한 발명설명서다. 기본 CoC와 가드의 결합, 후보의 목표·가드 공동 충족, 허용 후보의 효용 비교, 학습 정답에 따른 파라미터 갱신으로 이어지는 구성은 논문과 잘 연결된다. 예비 청구항 18개, 요약서, 적용 분야와 도면 7개도 포함되어 있어 기술 검토의 출발 자료로 사용할 수 있다.

다만 다음 세 가지는 우선 보완해야 한다.

1. **논문에 적힌 일반 절차와 실제 코드의 구현 수준이 다르다.** 시간·다중 주행 코드에서는 목표 미완료 후보를 먼저 제거하지 않고, 교착 후보의 진행도가 낮아 정답에서 탈락하도록 한다. 현재 데이터에서 결과가 같다는 사실과 일반 알고리즘의 동일성은 구분해야 한다.
2. **쌍대 데이터, 쌍대 손실, 교란 통제를 구분해야 한다.** 같은 장면의 두 계약은 실제 학습 자료에도 포함된다. 쌍을 공동 처리하는 별도 손실과 교란 표본을 이용한 개선 학습은 확인된 기본 학습과 다르다.
3. **본문 중복과 수치 불일치가 있다.** 2절 및 3.7절이 중복되고, 본문 3.6절의 3.5 m가 도 6·논문의 5.5 m와 다르다.

문서가 스스로 합성 후보 선택의 한계와 미관측 시간값에서의 성능 저하를 밝힌 점은 적절하다. 이 한계를 유지하면서 구현과 설명의 대응을 명확하게 만드는 것이 우선이다.

## 2. 실제로 설명하는 발명

입력은 장면 `x`, 원인과 행동목표를 담은 CoC `R`, 실행 가드 `G`, 후보 집합 `T(x)`이다. `R`과 `G`를 결합한 문맥을 만들고, 다음 정답을 계산한다.

```text
F = {τ ∈ T(x) | Goal(τ, R) = 1 and Sat(τ, G) = 1}
τ* ∈ argmax U(τ),  τ ∈ F
학습 입력 = (장면, CoC+가드, 후보 설명·측정값)
학습 목표 = τ*의 후보 식별자
```

이 구조의 기술적 의미는 가드가 입력 문장에만 존재하는 것이 아니라 **정답을 결정하는 조건으로도 사용된다**는 데 있다. 높은 효용을 가진 위반 후보와 가드를 지키지만 목표를 완료하지 못하는 후보를 정답에서 제외하려는 설계다.

학습 후 모델은 후보를 선택한다. 결정적 외부 검증과 재선택·대체동작은 추가 실시예로 제시되어 있다. 실제 가드의 자동 생성, 연속 궤적 생성, 실차 제어 안전성은 주 실험에서 입증한 범위에 포함되지 않는다.

주의할 점은 `Goal`과 `Sat`을 모두 필수조건으로 쓰는 것과 **반드시 Goal을 먼저 검사해야 한다**는 것은 다르다는 것이다. 두 판정이 같은 후보 속성에 대한 순수 판정이라면 필터 적용 순서를 바꾸어도 허용집합은 같다. 순서 자체의 특별한 계산상 효과를 주장하려면 별도 근거가 필요하다.

### 3.1 목표 미완료 후보의 처리: 중요한 구현 차이

시간 과제의 [`target_for()`](../../experiments/vlm_guard_learning/temporal_guard_world.py)는 진입 시각이 없는 정지 후보도 허용 후보로 남기고 진행도 최대값을 선택한다. 생성 데이터는 짧은 대기 후보 진행도 100, 긴 대기 후보 85, 교착 후보 0으로 구성되어 있으므로, 허용되는 목표 완료 후보가 존재하면 교착 후보가 선택되지 않는다.

다중 주행의 [`admissible()`와 `target_for()`](../../experiments/vlm_guard_learning/maneuver_guard_world.py)도 `goal_complete=False`인 후보를 비위반으로 취급한 뒤 진행도로 정답을 결정한다. 코드 주석에도 교착 후보는 진행도에서 밀린다고 적혀 있다. 정적 과제는 [두 후보가 모두 목표를 완료하도록 설계](../../experiments/vlm_guard_learning/candidate_guard_world.py)되어 별도 목표 필터가 필요하지 않다.

따라서 **현재 합성 후보에서 얻은 정답은 논문의 목적식과 부합하지만, 일반적인 후보 집합에 대해 Goal 필터를 먼저 실행한 구현 증거는 아니다.** 예를 들어 목표 미완료 후보의 효용이 완료 후보보다 높은 경우, 또는 목표·가드 공동 충족 후보가 없는 경우에는 두 알고리즘의 동작이 달라질 수 있다. 이는 기존 보고 수치가 틀렸다는 뜻이 아니라, 발명설명서 3.4절·청구항 5·도 4의 일반적 절차와 실험 구현의 대응을 더 정확히 써야 한다는 뜻이다.

수정 방향은 다음과 같다.

- 실제 실시예: 교착 후보의 진행도가 0이고 허용되는 완료 후보가 존재하는 구성에서 정답이 목적식과 일치함을 설명한다.
- 일반 방법: 목표 필터를 명시하는 의사코드와 입출력 예시를 추가한다.
- 필터 순서 자체가 중요한 특징이라면, 순서가 드러나는 구현과 검증 근거를 별도로 확보한다.

이번 분석에서는 기존 실험 코드를 수정하거나 새로운 학습을 수행하지 않았다.

### 3.2 쌍대 계약 데이터와 쌍대 손실

[`generate_temporal_examples()`](../../experiments/vlm_guard_learning/temporal_guard_world.py)는 각 장면마다 `short`와 `long` 계약을 생성한다. [`main()`](../../experiments/vlm_guard_learning/train_qwen_temporal_guard_lora.py)은 이 생성 함수를 `split="train"`에도 사용한다. 따라서 문서 3.6절·8절의 “주로 평가에 사용”이라는 설명은 다음처럼 구체화하는 편이 정확하다.

> 동일 장면에 대한 두 계약은 학습 및 평가 자료에 포함된다. 확인된 학습 구현은 각 계약의 정답 후보 토큰을 감독하는 방식이며, 계약 쌍을 공동 처리하는 전용 쌍대·대조 손실은 추가 실시예에 해당한다.

시간 과제 학습은 개별 표본을 섞는 DataLoader와 `model(...).loss`를 사용한다. 프롬프트 위치는 손실 대상에서 마스킹되고 정답 응답 토큰을 학습한다. 문서의 “분류 교차엔트로피”는 개념적으로 대응할 수 있지만, 실제 구현을 설명할 때는 **후보 식별자 응답에 대한 언어모델 지도학습 손실**이라고 쓰는 것이 정확하다.

청구항 9의 쌍대·대조 손실을 구체화하려면 최소한 쌍 구성 단위, 출력 분포, 손실식, 정답 지도손실과의 결합, 후보 식별자 변경 시 대응 관계를 명시해야 한다. 단순히 두 출력이 다르도록 하는 조건만으로는 두 출력이 모두 정답이라는 보장이 없다.

### 3.3 교란 통제와 hard negative

확인된 `SHUFFLED_GUARD` 조건은 가드와 정답의 대응을 깨뜨린 별도 모델을 학습하여 올바른 대응 학습의 효과를 비교하는 통제다. 이것은 올바른 모델에 부정 예시를 넣어 성능을 개선하는 hard-negative 학습과 다르다.

문서 3.5절 및 청구항 10은 두 용도를 함께 적는다. 유지하려면 “비교 통제자료”는 현재 증거에 연결하고, “음성 학습자료”는 어떤 출력에 어떤 방향의 손실을 줄 것인지 추가로 설명해야 한다. 잘못된 가드-정답 대응을 일반 정답처럼 학습시키는 것만으로는 개선 학습이 되지 않는다.

## 4. 예비 청구항의 기술적 검토

아래 표는 청구항의 기술 구성과 현재 증거의 관계다. 법적 권리범위 판정은 아니다.

| 항 | 현재 의미 | 보완할 사항 |
|---|---|---|
| 1 | CoC·가드 결합 → 공동 충족 후보의 효용 비교 → 정답 기반 모델 학습 | 가장 일관된 중심 구성이다. Goal·Sat·U의 입력 데이터와 계산 예시, 허용집합 존재 가정을 명시한다. |
| 2–4 | 가드 유형, 자연어 후단 결합, 후보 속성 | 논문 근거가 있다. 모든 가드 유형의 실제 검증을 완료했다고 표현하지 않는다. |
| 5 | 목표 필터 → 가드 필터 → 효용 비교의 실행 순서 | 논문 서술과 실제 코드의 차이를 3.1절처럼 해소한다. 순서 자체를 차별성으로 단정하지 않는다. |
| 6 | 평가 구간 안에 목표를 완료하지 못한 정지·대기 후보 판정 | 유한 평가 구간 내 목표 미완료라는 조작적 정의를 유지한다. 영구 교착이 입증된 것과 구분한다. |
| 7 | 식별자와 행동 역할의 대응 변경 | 현재 코드의 순환 배치를 구체적 실시예로 제시할 수 있다. |
| 8 | 같은 장면에서 서로 다른 가드와 정답 생성 | 기존 학습 데이터 생성에도 대응한다. 전용 손실이 없어도 설명 가능한 구성이다. |
| 9 | 계약 쌍의 공동 손실 | 현재 확인한 학습과 구분되는 확장이다. 손실식과 작동 예시가 필요하다. |
| 10 | 교란 표본을 학습 또는 통제로 사용 | 통제와 개선 학습의 목적·손실 방향을 분리한다. |
| 11–12 | VLM·효율적 미세조정·복수 가드 논리곱 | 구현 및 논문과 연결하기 쉽다. 실제 시험한 가드 조합을 구체적으로 적는다. |
| 13 | 학습 완료 모델의 추론 | 제목은 독립항이지만 문장이 청구항 1의 학습 방법을 참조한다. 항 분류와 참조 구조의 일관성을 확인한다. |
| 14 | 외부 검증 실패 시 재선택·대체동작 | 확장 실시예다. 검증기에 전달되는 가드 경로, 불확실 상태, 후보 소진과 재선택 종료 조건을 설명한다. |
| 15–17 | 학습 장치와 선택적 모듈 | 기능별 입출력과 도면 부호를 연결한다. “중 하나 이상”이라는 표현이 기본 장치 전체와 어떤 관계인지 명확히 한다. |
| 18 | 방법을 수행하는 기록매체 | 참조하는 방법 범위가 의도한 학습·추론 기능을 정확하게 포괄하는지 문서 내부적으로 확인한다. |

### 명세의 구체성을 높이는 최소 추가 내용

1. **완전한 수치 실시예 하나:** 장면·CoC·가드, 각 후보의 Goal·Sat·U, 제외 이유, 정답 식별자, 실제 학습 입력·출력을 한 표로 연결한다.
2. **허용 후보가 없는 경우:** 논문은 공동 충족 후보가 적어도 하나 있다고 가정한다. 학습 표본 제외·후보 재생성·실행 시 대체동작 중 어떤 처리를 하는지 정하고, 대체동작을 목표 완료 정답과 혼동하지 않는다.
3. **동률 처리:** 최대 효용 후보가 여러 개일 때 복수 정답으로 처리할지 결정적 선택 규칙을 둘지 명시한다.
4. **가드 판정의 출처:** 합성 데이터에서 이미 알려진 구조화 값으로 판정하는 것인지, 자연어에서 추출하는 것인지 구분한다. 현재 논문은 일반 자연어 파서의 정확성을 입증하지 않는다.
5. **수치·시간 정의:** 단위, 경계의 등호 포함 여부, 연속 시간과 샘플 시각, 목표 완료 평가 구간을 명시한다.
6. **학습 모델의 역할:** 규칙 기반 정답 생성기가 이미 후보를 계산할 수 있는 상황에서 이를 모델로 학습시키는 목적을 설명한다. 현재 자료만으로 계산시간 단축이나 비용 절감을 입증했다고 쓰지는 않는다.

## 5. 실험 수치와 효과 표현

발명설명서 5.1절의 세 줄은 지정 논문의 [5장](../../paper/manuscript/latex-kiee-review-2022/sections/05-experiments.tex), [8장](../../paper/manuscript/latex-kiee-review-2022/sections/08-conclusion.tex)과 일치한다. 기존 [실험 결과 검산 기록](../../paper/manuscript/latex-kiee-review-2022/EXPERIMENT_RESULT_AUDIT.md)도 같은 집계값을 기록한다. 이번 작업은 문서·기존 기록 대조이며 GPU 실험 재실행은 아니다.

|---|---|---|
| 표준 시간, 기본 CoC | 위반률 `0.319 ± 0.052` | 일치. 제약을 받지 않은 정보 부재 기준선이다. |
| 표준 시간, 제약 통합 CoC | 위반률 `0.000 ± 0.000` | 일치. 가드 준수 목표 완료율도 `1.000`이다. |

이 결과에 붙일 실험 조건은 Qwen3-VL-2B-Instruct, LoRA, 세 seed(42·17·123), seed당 시간 학습 192장면·384계약 예, 평가 48장면·96계약 예다. 표준 평가는 학습과 같은 문장 틀·수치 범위의 미사용 장면이다.

효과 표현에서 주의할 사항은 다음과 같다.

- “위반 후보의 정답 배제”는 정답 생성 단계의 성질이다. 학습된 모델이 추론 중 위반 후보를 절대로 출력하지 않는다는 뜻은 아니다.
- 기본 CoC에는 계약을 구별할 정보가 없으므로 그 대비만으로 CoC 결합 방식 자체의 우수성을 입증하지 않는다. 동일 형식의 올바른 대응 학습과 교란 통제 비교도 함께 설명한다.
- 논문의 시간 과제 영상 절제는 정확도를 낮췄지만, 다중 주행 과제 일부는 영상 개입에도 정확도를 유지했다. 따라서 모든 성과를 실제 시각적 장면 이해의 개선으로 표현하지 않는다.
- 검증기와 정답은 같은 합성 과제 정의에 의존한다. 모델과 분리된 계산이라는 사실이 독립된 실제 도로 안전 정답을 의미하지는 않는다.
- 외부 차단장치의 보조 폐루프 결과는 별도 소형 신경망 실험이다. 이를 Qwen 후보 선택 모델의 실차·폐루프 검증 결과로 합치지 않는다.

## 8. 권장 보완 순서

1. **기존 자료 정합성 수정:** 중복 절·제목, 3.5/5.5 m, 학습 데이터 사용 설명, 통제와 hard negative 구분을 정리한다.

원본 HWP의 `BodyText/Section0`에서 텍스트 레코드 368개를 읽고 내장 PNG 7개를 확인했다. 표의 텍스트는 문단 순서로 대조했고 내장 이미지의 텍스트는 별도로 확인했다. 스크립트 실행·문서 외부 전송 없이 로컬 추출을 수행했으며, 웹 확인에는 문서에 이미 적힌 공개 문헌 식별자와 공개 페이지를 사용했다.

배치 검증에서 관련 Markdown의 로컬 링크 24개와 원본 해시를 확인했다. 필수 명령 `python3 cli/checks/file_naming.py`는 실행했으나, 이번 변경 외의 파일 4개 때문에 저장소 전체 검사는 실패했다. 해당 항목은 다른 프로젝트 산출물의 `m16_geometry_candidate_review (1).csv`, `m16_geometry_candidate_review (1).json`, `scene18_scene_cnl_review (1).json`과 루트 `portal_exec.md`다. 이번 작업 파일에 대한 명명 위반은 보고되지 않았다. 기존 항목은 변경하지 않았다.
