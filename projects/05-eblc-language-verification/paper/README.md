# EBLC Language Verification paper

This directory will own the independent EBLC manuscript, figures, supplement, and submission
assets. It does not own the reusable platform implementation.

## Provisional paper scope

- evidence- and lifecycle-aware contract representation
- provenance-preserving lowering to runtime, Core, and SMT targets
- bidirectional underconstraint and overconstraint mutation evaluation
- independent semantic-conformance evidence, cost, limitations, and failure analysis

## Manuscript start gate

A claim-bearing manuscript starts only after `EB-M01` establishes a defensible prior-art boundary
and `EB-M02` freezes baselines, benchmark units, independent oracles, metrics, and failure criteria.
Until then, the canonical source is the
[`research plan`](../docs/plans/01_RESEARCH_PLAN_V01.md), not a draft paper.
